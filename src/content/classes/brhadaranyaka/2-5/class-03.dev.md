ॐ श्रुतिस्मृतिपुराणानाम् आलयं करुणालयम्। नमामि भगवत्पादं शङ्करं लोकशङ्करम्॥ शङ्करं शङ्कराचार्यं केशवं बादरायणम्। सूत्रभाष्यकृतौ वन्दे भगवन्तौ पुनः पुनः॥ ईश्वरो गुरुरात्मेति मूर्तिभेदविभागिने। व्योमवद्व्याप्तदेहाय दक्षिणामूर्तये नमः॥ ॐ सह नाववतु। सह नौ भुनक्तु। सह वीर्यं करवावहै। तेजस्विनावधीतमस्तु मा विद्विषावहै॥ ॐ शान्तिः शान्तिः शान्तिः॥ ॐ नमो ब्रह्मादिभ्यो ब्रह्मविद्यासंप्रदायकर्तृभ्यो वंशऋषिभ्यो नमो गुरुभ्यः॥

We are looking into the introduction of **मधुब्राह्मण**. So we saw **आचार्य** started by saying, this **मधुब्राह्मण** is for what purpose? And then he said, some people say, they try to divide by saying, this much is **श्रवणम्**, this much is **मननम्**, this much is **निदिध्यासनम्**. I don't see the justification to necessarily divide it in that way. But in any way, whether we take it this way or that way, finally you understand one thing: that the entire chapter is meant to make us understand **ब्रह्म**. That we can agree with. So, you know, you stay away from the controversies and you show where the agreement lies. In that agreement, we are in good shape, right? So we agree with that much.

So the introduction was given. Now we have to enter the **मधुब्राह्मण**. So we need to see that introduction has a value, obviously. So you can look at it as if—because the entire thing is knowledge-based, something is blocking our understanding. What blocks it, we don't understand many a time. Okay. Where is it? So we saw in **सम्बन्धभाष्य**, **भाष्यकार** said that this **मधुब्राह्मण**, what is the basic thing? **परस्परोपकार्योपकारकभूतं** **जगत्सर्वं** **पृथिव्यादि**. They are mutually supporting each other, mutually depending on each other in a way. And whatever is like that, **लोके** **परस्परोपकार्योपकारकभूतं** **तत्** **एककारणपूर्वकम्** **एकसामान्यात्मकम्** **एकप्रलयं** **च** **दृष्टम्**. Whatever is seen in the world to be mutually dependent, they are seen to be really having one reality. **तस्मात्**, therefore—not just **पृथिव्यादि**, it stands for the whole cosmos, **जगत्**. This is **जगत्**. **परस्परोपकार्योपकारकत्वात्**. What? Because one supports the other, the other supports one. Therefore, it should be **तथाभूतम्**. What is **तथाभूतम्**? **तथाभूतम्** means **एकात्मकम्**. It should have one reality. **इति** **एषः** **अर्थः** **अस्मिन्** **ब्राह्मणे** **प्रकाश्यते**. Because for all the beings, this **पृथिवी** is created. The entire **जगत्** is **कर्मफल**, **अनुभव**. Therefore, why is the **पृथिवी** there? For the **अनुभव** of all the living beings. **इयं** **पृथिवी** **सर्वेषां** **भूतानां** **मधु**.

Now second, **अस्यै** **पृथिव्यै**. That you should do **विभक्तिविपरिणाम**. You should make it **षष्ठी**. So **चतुर्थी** doesn't work here. **षष्ठ्यर्थे** **चतुर्थी**. Doesn't say **मधूनि**. **मधु**. So what is this **पृथिवी**? It is the **कार्य** of all the **भूत**s. All the **भूत**s are **कार्य** of **पृथिवी**. **पृथिवी** is the **कार्य** of all the **भूत**s. Mutual dependence.

Is that it? We have looked at the **स्थूल**. Now what about **सूक्ष्म**? He says, **यश्चायम्** **अस्यां** **पृथिव्याम्**. In this **पृथिवी**, what is there in this **पृथिवी**? And this **सूक्ष्मशरीर** does not begin every time a new body begins. It travels. Therefore, **अमृतमयः**, relatively **अमृत**. **पुरुषः**. It fills up this **स्थूल**, correct? Every **स्थूल** is as though filled up by **सूक्ष्म**. **प्राणमय**. **अन्योऽन्तर** **आत्मा** **प्राणमयः**. That idea comes here also. **अमृतमयः** **पुरुषः**.

So there is a **सूक्ष्मशरीरी** in the **पृथिवी**, in the **आधिभौतिक** **पृथिवी**. And then this body, **अध्यात्मम्**, in that also there is a **सूक्ष्मशरीर**. So **यश्चायमध्यात्मम्**. So you will see this phrase everywhere. **यश्चायमध्यात्मम्**. What is **अध्यात्मम्**? **आत्मनि**. Where we think of me as myself.
